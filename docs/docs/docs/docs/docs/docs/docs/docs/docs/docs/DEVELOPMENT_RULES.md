# SedatOS AI Development Rules

## 1. Geliştirme Prensibi

SedatOS AI geliştirmelerinde öncelik:

- Stabilite
- Güvenlik
- Ölçeklenebilirlik
- Kullanıcı deneyimi
- Kurumsal kalite

olmalıdır.

---

# 2. Kod Değişikliği Kuralları

Her değişiklik öncesi:

1. Mevcut sistem analiz edilir.
2. Bağımlılıklar kontrol edilir.
3. Güvenlik etkisi değerlendirilir.
4. Test yapılır.
5. Değişiklik kayıt altına alınır.

---

# 3. AI Geliştirme Kuralları

AI sistemleri:

- Sadece cevap veren yapı olmayacak.
- Veri analiz edecek.
- Öneri oluşturacak.
- Riskleri gösterecek.
- Karar desteği sağlayacak.

---

# 4. Veri Güvenliği

Zorunlu kurallar:

- Her şirket verisi company_id ile ayrılır.
- Kullanıcı sadece yetkili olduğu veriyi görür.
- RLS politikaları aktif olmalıdır.
- Hassas veriler korunmalıdır.

---

# 5. Kullanıcı Deneyimi

Arayüz hedefleri:

- Premium tasarım
- Basit kullanım
- Hızlı erişim
- Kişiselleştirme
- Mobil uyumluluk

---

# 6. Kurumsal Standart

SedatOS AI;

bireysel uygulama mantığıyla değil,

kurumsal yazılım standartlarıyla geliştirilmelidir.

Desteklenecek yapılar:

- Şirketler
- Departmanlar
- Kullanıcı rolleri
- Yönetici panelleri
- Raporlama sistemleri

---

# 7. Test Süreci

Her modül için:

Kontrol:

- Çalışıyor mu?
- Güvenli mi?
- Ölçeklenebilir mi?
- Kullanıcı deneyimi uygun mu?

---

# 8. Dokümantasyon

Her önemli geliştirme:

- Açıklanmalı
- Kaydedilmeli
- Sürüm kontrolünde tutulmalı

---

# 9. Nihai Hedef

SedatOS AI;

dünya standartlarında,
güvenilir,
kurumsal seviyede
yapay zeka işletim sistemi olarak geliştirilecektir.
