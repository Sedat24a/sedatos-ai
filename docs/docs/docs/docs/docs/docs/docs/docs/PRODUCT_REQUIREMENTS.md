# SedatOS AI Product Requirements Document

## 1. Ürün Tanımı

SedatOS AI;

kişisel yaşam yönetimi, şirket yönetimi ve yapay zeka destekli karar sistemlerini tek platformda birleştiren AI Operating System'dir.

Hedef kullanıcılar:

- Bireysel kullanıcılar
- Şirket yöneticileri
- KOBİ'ler
- Holding yapıları

---

# 2. Temel Modüller

## Personal OS

Kişisel yönetim:

- Takvim
- Görevler
- Notlar
- Hedefler
- Finans takibi
- Sağlık takibi

---

## Business OS

Kurumsal yönetim:

- Şirket yönetimi
- Departmanlar
- Personel
- Projeler
- CRM
- Doküman yönetimi
- İş süreçleri

---

## AI OS

Yapay zeka katmanı:

- Araştırma
- Analiz
- Karar desteği
- Tahmin
- Otomasyon

---

# 3. Kullanıcı Rolleri

## Founder / CEO

Yetkiler:

- Holding görünümü
- Stratejik analiz
- Tüm şirket raporları


## Company Admin

Yetkiler:

- Şirket yönetimi
- Kullanıcı yönetimi
- Süreç yönetimi


## Manager

Yetkiler:

- Departman yönetimi
- Ekip analizi


## Employee

Yetkiler:

- Kendi görevleri
- Kendi performansı

---

# 4. Dashboard Sistemi

Dashboard kullanıcıya göre değişmelidir.

## CEO Dashboard

Gösterilecekler:

- Şirket durumu
- KPI
- Riskler
- Finans özeti
- AI önerileri


## Manager Dashboard

Gösterilecekler:

- Ekip durumu
- Projeler
- Görevler
- Performans


## Personal Dashboard

Gösterilecekler:

- Günlük plan
- Hedefler
- Verimlilik
- Kişisel analiz

---

# 5. AI Çalışma Prensibi

AI cevap sistemi yerine analiz sistemi olarak çalışmalıdır.

Her analiz:

1. Veriyi toplar
2. Durumu değerlendirir
3. Riskleri belirler
4. Fırsatları çıkarır
5. Aksiyon önerir

---

# 6. Kurumsal Gereksinimler

Sistem desteklemeli:

- Çoklu şirket yapısı
- Rol bazlı yetki
- Güvenli veri erişimi
- Denetim kayıtları
- Raporlama
- Otomasyon

---

# 7. Premium Hedef

SedatOS AI;

sadece bir uygulama değil,

kişilerin ve şirketlerin dijital çalışma merkezi olacak şekilde tasarlanmalıdır.
